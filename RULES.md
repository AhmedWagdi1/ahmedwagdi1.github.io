# Agent Rules

Always read and apply the following rules when performing actions or making changes in this workspace:

1. **Read Memory Before Starting**:
   - Every time you start a task, you must read the `MEMORY.md` file first to understand the workspace state and make things clearer.

2. **Update Memory on Completion**:
   - Every time you finish a task or make an update, you must update the `MEMORY.md` file with the changes made.

3. **Commit and Push Updates**:
   - After every update, commit the changes to Git and push them to the remote repository.

4. **Follow Technology Stack Guidelines**:
   - Core: Use standard HTML & Vanilla JavaScript.
   - Styling: Use Tailwind CSS as configured in the HTML file for compatibility and styling consistency.

5. **Verify Correctness**:
   - Ensure app package IDs, URLs, and static details are correctly formatted and tested.
   - Ensure responsive designs, clean layouts, and accessibility standards are maintained.
